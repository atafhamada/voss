# Security Policy

## Supported versions

Only the latest release on PyPI is supported:

| Version | Supported |
|---------|-----------|
| 0.5.x   | yes       |
| < 0.5   | no        |

## Reporting a vulnerability

Please **do not** open a public issue for security reports.

Send an email to: `ataf.hamada2@gmail.com`

Include:
- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response timeline

- Acknowledgement within 72 hours.
- Status update within 7 days.
- Fix or mitigation as soon as possible, coordinated with you.

## Disclosure

We follow coordinated disclosure. Once a fix is released, we will publish
a security advisory on GitHub.

## Scope

This policy covers the VOSS library, Python bindings, and published wheels.
